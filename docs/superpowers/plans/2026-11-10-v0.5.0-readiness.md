2. **Ownership of runtimes.** A runtime that the SDK builds from a descriptor is closed exactly once by `IndeRunWeb.close()`. A runtime the app injected is never closed by the SDK. Tested in Task 2.

**Rules (en-US output, also used for en-GB):**
- **Cardinals** go up to 999,999,999,999 in US style, with no "and": `101` → "one hundred one", `21` → "twenty-one". Comma groups such as `1,250` are one number. Runs of two or more digits that start with `0`, and runs over 12 digits, are read digit by digit. A lone `0` is "zero".
- **Decimals:** "point", then the digits.
- **Negatives:** `-5` after whitespace or at line start → "minus five".
- **Ranges:** `3-4` and `3–4` → "three to four".
- **Ordinals:** `1st`, `2nd`, `3rd`, `Nth` → ordinal words.
- **Dates:** after a full month name, a day number (1–31, optionally with an ordinal suffix) is read as an ordinal. A following `, YYYY` (1000–2999) is read with `year()`:
  - 2000–2009 → "two thousand[ d]"
  - 2010–2099 → "twenty yy"
  - 1100–1999: `xx00` → "xx hundred", `xx0d` → "xx oh d", otherwise "xx yy"
  - anything else → cardinal
  A four-digit number anywhere else is a cardinal.
- **Clock:** `H:MM` reads as "H MM", with `:00` silent and `:0d` read as "oh d". `am`, `pm`, `a.m.` and `p.m.` (any case, optional space) become "a m" / "p m".
- **Money:** `$ € £` followed by an amount → "dollar(s)", "euro(s)", "pound(s)". Cents read as "and N cent(s)" for `$` and `€`, and "and N pence" for `£`. `$0.50` → "fifty cents".
- **Percent and symbols:** `N %` or `N%` → "N percent". `#N` and `No. N` → "number N". `&` → "and".
- **Units** apply only directly after a number: singular for 1, plural otherwise. Never `in`. `km/h` → "kilometers per hour", `°C` → "degrees Celsius".
- **Glued letters:** a letter run glued to digits splits them: `B12` → "B twelve".
- **Abbreviations:** `etc. approx. e.g. i.e. vs. Dr. Mr. Mrs. Ms. Prof. Jr. Sr.` → "et cetera", "approximately", "for example", "that is", "versus", "Doctor", "Mister", "Missus", "Miz", "Professor", "Junior", "Senior". The period of `etc.`, `a.m.` and `p.m.` is kept only when the line ends there or when whitespace and an uppercase letter follow. It is the sentence end. Every other listed abbreviation always loses its period: `vs. Mrs.` is not a sentence end.
