# Neural Speech: ORT Executors and the Articulino Pipeline (PR 4a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the neural speech provider family speak with a real model: an ONNX Runtime `SpeechGraphExecutor` on every SDK (CPU execution provider), the Articulino text-to-PCM pipeline in the runtime-free modules, voices as precomputed safetensors bundles, a Python tool that prepares packages and voices, a shared fixture that pins the host math, and env-gated tests that run the real graphs.

**Architecture:** Nothing in the provider changes. The ORT modules (`IndeRunOnnxProviders`, `inderun-onnx-providers`, `providers/neural-speech/ort-executor.ts`) implement `SpeechGraphExecutor` and compose it with a pipeline runtime into one `NeuralSpeechRuntime` the app passes to the provider. The pipeline (`articulino/`), the safetensors reader and the `SpeechPackageFiles` seam live in the runtime-free neural speech modules so Core AI (PR 5) reuses them. The host math is pinned by `contracts/fixtures/speech/articulino-pipeline.json`, generated by the Python tool from the same functions that prepare voices; every SDK runs the fixture against a scripted fake executor in CI, and the real graphs only under `INDERUN_NEURAL_SPEECH_MODEL_DIR`.

**Tech Stack:** TypeScript (Vitest; `onnxruntime-web` wasm backend, optional peer, structural type), Swift 5.9 (`onnxruntime-swift-package-manager` 1.24.2, XCTest), Kotlin (`onnxruntime-android` 1.31.0, Robolectric, instrumented androidTest), Python 3.12/3.13 (`onnxruntime` 1.31, `numpy`, `safetensors`, `soundfile`) under `tools/neural-speech/`.

**Spec:** `docs/superpowers/specs/2026-11-04-neural-speech-design.md` section C (placement, seams), section G (Articulino first), "Phases / PRs" (PR 4); rulings of the owner's decision proxy in the session scratchpad `pr4-decision.md` (summarised in Global Constraints); ORT survey `pr4-ort-survey.md`; spike findings `spike/findings.md` (same scratchpad).

## Articulino host math (normative; Tasks 1, 2, 4, 6 implement it identically)

Letters: lowercase the text; apply the replacement map `’ ‘ ` ´ → '`, `“ ” „ « » → "`, `– — → -`, `… → .`, `ø → ö`, `æ → ä`, `ð → d`, `þ → th`; a code point not in the charset and not one of `ä ö ü ß` is NFKD-decomposed with combining marks dropped; code points still outside the charset are dropped; whitespace runs collapse to one space; leading/trailing spaces are trimmed. Id of a letter = 1 + its index in `charset`; language id from `languages[lang]` (`de` 0, `en` 1), one per letter. The model input is `text_ids = [0] + ids` (i64), `language = [lang] + langs` (i64), `text_mask = [0] + [1] * n` (i64; the tool-rewritten graph casts it to bool). `isLetter(id)` = the charset character is alphanumeric (digits count).

Durations (10 ms units): `d = min(exp(log_durations) * mask, max_duration_units) / speed` (float32); if `letter_rate > 0`: over letters with `isLetter` from index 1, `x = max(d, 0.5)`, `x = min(x, 3 * median(x))`, `rate = count / (sum(x) / 100)`, then scale those `x` by `rate / (letter_rate * speed)` and write them back; then `d[0] = units * P`; `frames = ceil(sum(d) / units)`.

Frame condition for `j = P .. frames-1`: `end = cumsum(d)`, `start = end - d`, `lo = j*units`, `hi = lo+units`, `w_l = clamp(min(end_l, hi) - max(start_l, lo), 0) / units`, `cond[j-P] = Σ_l w_l * h[l]` (h = `text_features[0]`, shape (n+1, C)).

Flow steps: `shape = (1, frames-P, latent_dim)`; `x = noise(0)`; for `k, t in enumerate(times)`: `v = dit_step(x, t=[t], frame_cond=cond[None], voice_tokens, voice_vector, voice_cache).velocity`; `x1 = x + (1-t) * v`; if `k+1 < len(times)`: `t2 = times[k+1]`, `x = (1-t2) * noise(k+1) + t2 * x1`. Result `x1`.

Decode: `lead = min(prompt_latents frames, decoder_lead_in_frames)`; `z = concat(prompt_latents[:, -lead:], x1)` on axis 1; `wav = decoder(latents=z).waveform[0]`; apply the low shelf (RBJ cookbook, `A = 10^(db/40)`, `w = 2π f0 / sr`, `c = cos w`, `q = 2√A · sin(w)/2 · √((A + 1/A)(1/S − 1) + 2)`, `z = −1`: `b0 = A((A+1) + z(A−1)c + q)`, `b1 = −2zA((A−1) + z(A+1)c)`, `b2 = A((A+1) + z(A−1)c − q)`, `a0 = (A+1) − z(A−1)c + q`, `a1 = 2z((A−1) − z(A+1)c)`, `a2 = (A+1) − z(A−1)c − q`, all divided by `a0`; direct form II transposed in float64 over the whole waveform including the lead-in); drop the first `lead * samples_per_frame` samples; if `max|wav| > peak`: `wav *= peak / max|wav|`; append `round(pauseMs/1000 * sample_rate)` zeros; int16 = `round(clamp(x, −1, 1) * 32767)`.

Noise: `noise(k)` returns `frames-P` × `latent_dim` standard-normal float32 values; injectable (`NoiseSource`), default Box-Muller over the platform RNG.

## Review Focus

1. A letter run of more than 180 characters (long AAC sentence without punctuation) is split at the last `, ; : -` or space between letter 60 and 180, synthesized in pieces, and returned as one chunk; `splitLongSentence` fixture case `long_sentence_split` (Task 1) run on every SDK (Tasks 2, 4, 6).
2. A sentence whose letters are all dropped (emoji, symbols outside the charset) must not reach the graphs: the runtime yields one chunk holding only the trailing pause, `empty_after_letters` (Task 1; Tasks 2, 4, 6).
3. A voice bundle with the wrong `format` or a missing tensor refuses at `prepare` with a reason naming the voice id (`SafetensorsTests`/`safetensors.test.ts` "rejects a bundle without voice_cache", Tasks 2, 4, 6), and a package whose `voices[].file` is absent refuses at `availability` (`availability_requires_voice_files`, Tasks 2, 4, 6).
4. Cancelling mid-sentence stops the pipeline before the next graph call: the scripted executor counts calls after abort/cancellation (`cancel_between_graphs`, Tasks 2, 4, 6).
5. A missing `onnxruntime-web` module, a missing graph file, or an ORT load failure reports `available: false` with the reason, never a throw out of `availability` (Tasks 3, 5, 7).
