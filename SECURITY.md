# Security Policy

## Supported Versions

Security fixes go into the latest released minor version of IndeRun (the npm packages, the `IndeRun` Swift package and
the `app.independo.inderun` Maven artifacts). The Capacitor plugin has its own policy in
[independo-gmbh/capacitor-inderun](https://github.com/independo-gmbh/capacitor-inderun/blob/dev/SECURITY.md).

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, email [developers@independo.app](mailto:developers@independo.app). Include a description of the issue, steps to
reproduce, and the affected versions if known.

We'll acknowledge your report as soon as possible and keep you updated as we investigate and fix the issue.
